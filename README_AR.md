# كتالوج ADLA FOOD

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` مباشرة في المتصفح.
3. للنشر كرابط عام، ارفع `index.html` إلى أي استضافة مواقع ثابتة مثل Vercel أو Netlify أو GitHub Pages.

## التقنيات المستخدمة

- HTML5 لبناء واجهة الكتالوج.
- CSS3 للتصميم المتجاوب مع الموبايل، الألوان، البطاقات والحركات.
- JavaScript بدون إطار عمل لإدارة البحث، الفئات، الأحجام، الكميات والسلة.
- صور المنتجات مضمّنة داخل الصفحة لتسهيل نقل النسخة التجريبية.
- Font Awesome لأيقونة واتساب وبعض الأيقونات.

## ملاحظة مهمة

هذه نسخة Frontend تجريبية تعمل من ملف واحد. لا تحتوي حاليًا على قاعدة بيانات أو لوحة إدارة أو أرشفة طلبات حقيقية. إرسال الطلب الفعلي إلى واتساب وربط لوحة الموزع يحتاجان مرحلة Backend أو خدمة إدارة محتوى.
